## Артефакты только из текущего проекта

План, ревью, research, файл цели и любой другой артефакт на входе принимай только из текущего проекта. Путь из другого проекта — ошибка пользователя: такой файл не читай и по нему не работай.

1. **Корень проекта** — `git rev-parse --show-toplevel` из рабочей директории, вне git — сама рабочая директория. Своими считаются и другие worktree этого репозитория из `git worktree list`.
2. **Проверка до чтения.** Относительный путь разрешай от рабочей директории, затем раскрой symlink (`realpath`). Путь должен лежать внутри корня проекта или его worktree; `file://`-ссылку проверяй так же.
3. **Чужой путь — остановка.** Не читай файл, не копируй его в проект и не подбирай похожий артефакт вместо него. Заверши работу `blocked: артефакт из другого проекта`, назови путь и корень текущего проекта и попроси указать артефакт этого проекта. Если чужой артефакт нужен намеренно, пользователь сам переносит его в `docs/artifacts/` текущего проекта и передаёт новый путь.
4. **Связанные пути — тоже.** Правило действует для путей от оркестратора и для путей внутри артефакта: `plan` в ревью, связанные план и research.
